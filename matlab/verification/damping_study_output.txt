===== ROD contrast =====
  rod at coincidence: 0 propagating points in 995-1005 Hz -> NO passband.
  |cos mu| = 1+gamma_1 = 8.9955 > 1, Eq. (3.8): the gaps FUSE, so damping is a
  non-question for the rod -- there is nothing to smear out.  The survival
  of a passband is a two-channel (count) effect; damping tests whether it
  survives OBSERVABLY, and for the beam the answer is set by eta_crit above.

===== PHYSICAL INTERPRETATION =====
  eta_crit = 3.0e-05 - 5.9e-05 for host/combined loss (computed above).  Pure resonator loss
  has no intrinsic continuum threshold because the Bragg state is pinned.
  Realistic host loss
  factors for a sandwich beam:
    viscoelastic polymer core   eta ~ 0.1 - 1      (3-4 orders ABOVE eta_crit)
    structural foam core        eta ~ 0.01 - 0.1   (2-3 orders ABOVE)
    metal facesheets (bending)  eta_b ~ 1e-3 - 1e-2
    even an all-metal analogue  eta ~ 1e-3         (>1 order ABOVE)
  => the residual passband is NOT observable for any real sandwich beam.
  It is a property of the CONSERVATIVE complex band structure (the absence of
  merging is an exact statement about the lossless dispersion relation);
  under realistic damping the least-decaying wave decays at ~kappaL/cell and
  the passband is indistinguishable from its flanks.  Observing it would need
  eta below about 3e-05, unattainable for a viscoelastic-core sandwich.
